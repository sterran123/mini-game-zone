# 30초 던전 🐱

매 판 새로운 던전에서 열쇠를 찾아 계단으로 탈출하는 **미니 로그라이크**.
한 판은 최대 30초 — 슬라임이나 함정에 닿으면 즉시 실패합니다.

## 규칙

- 🔑 열쇠를 먼저 먹고 → 🚪 계단으로 이동하면 탈출 성공
- 30초 안에 못 빠져나가거나 🟢 슬라임·🔥 함정에 닿으면 실패
- 슬라임은 내가 2칸 움직일 때마다 1칸씩 쫓아옵니다
- 맵은 매 판 절차적으로 생성됩니다 (벽·함정·슬라임·열쇠·계단 위치가 랜덤, 탈출 불가능한 맵은 자동 재생성)

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 / WASD | 이동 (한 번에 한 칸) |
| P / Esc | 일시정지 · 재개 |
| R | 재시작 |
| Enter | 시작 · 다시 시작 |
| 화면 화살표 | 터치 조작 (모바일) |

## 실행

- 배포: https://sterran123.github.io/30s-dungeon/ (GitHub Pages)
- 로컬: `node tools/serve.mjs` → http://localhost:8081

## 기술 메모

- 순수 HTML/CSS/JS — 프레임워크·빌드 없음
- 효과음·배경음: WebAudio API로 실시간 생성 (오디오 파일 없음)
- 기록 저장: `localStorage` — 전적·최고기록·판별 로그 보존, 손상 시 기본값 복구
- 난이도 값은 `game.js` 상단 `CONFIG`에 모여 있음 (슬라임 수·함정 수·제한시간·벽 비율)
